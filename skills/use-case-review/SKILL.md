# ユースケースをレビューする

依頼に応じて、次のどのレビューを行うかと、対象のユースケース・資料を定める。複数を組み合わせる場合も、実際に確認した範囲を区別する。

- **要求レビュー**: 要求、ユースケース、初期ドメインモデル、画面の試作を照合し、利用者の望む振る舞いが具体的に表されているか確かめる。
- **予備設計レビュー（PDR）**: ロバストネス分析後の文章・図・更新したモデルを照合し、詳細設計へ渡す前に不足や矛盾を見つける。
- **文章だけの部分レビュー**: 語彙、対話、範囲、基本・代替コースなど、提示された文章から判断できる点を確認する。文章添削だけの依頼には全工程を求めず、図の接続やモデルとの整合を検証済みとはしない。

## 要求レビュー

- 重要な概念が業務の人にも分かる言葉で表され、本文とモデルで同じ意味か。is-aとhas-aの関係を具体例で説明できるか。初期モデルの完全性を求めない。
- 誰が何をし、システムがどう応じるか。「できる」「適切に処理する」だけで対話や結果を曖昧にしていないか。概念や画面の名前は具体的か。
- 目的、始点、終点が一つの利用シナリオとしてつながるか。範囲外や別ユースケースの内容を取り込みすぎていないか。
- 基本コースと必要な代替コースがあり、条件ごとのアクターとシステムの行動、復帰先か終了状態が分かるか。
- 機能要求そのものをシナリオ本文に混ぜず、関連する要求と対応付けているか。シナリオを満たすと利用者の望むことが実現するか。
- モックや画面がある場合、本文と相互作用が一致するか。確認に必要なものだけ使い、このレビューを見た目の磨き込みに広げない。

## 予備設計レビュー

このスキルで扱う書籍方式のPDRには、対象ユースケースのロバストネス図が必要である。図がない、または基本・代替コースの必要な部分を欠く場合は、[robustness-analysis](../robustness-analysis/SKILL.md)で作成・補完してから照合する。文章や表で整理した対応関係は準備や部分レビューに使えるが、図の検証と同等に扱わない。

- 記述を一文ずつ、接点（boundary、B）、処理・判断（control、C）、業務概念（entity、E）と照合する。入力、判断の根拠、必要な対象が欠けていないか。
- 基本・代替コースの各動作と分岐を文章から図へたどり、図の要素と接続から文章へも戻る。片側にしかない要素や、呼び出し先・復帰先・終了状態の食い違いを調べ、両方の修正箇所を示す。
- 画面入力から、保持する対象や属性、判断、表示に使うデータまで追えるか。必要な対象と属性が更新したドメインモデルにもあるか。フォーム実装が担うという理由で、必要な振る舞いを省かない。
- アクターはBを介してシステムと関わる。B同士、BとE、E同士を直接つながず、その間の働きをCで表す。CはB・E・他のCとつながる。接続規則に通るだけで十分とせず、各接続が本文のどの動作を表すか確かめる。
- 送信先とCが表す働きが明らかか。「表示する」なら何を表示するかまで具体化する。Cは論理的な機能であり、一つずつ実装クラスにする必要はない。詳細な実装責務やメソッドの配置、パターンの適用はこのレビューの対象外とする。

既知の技術制約と、詳細設計へ進むために今後確認・確定する前提を分け、記述や図との食い違いと未解決事項を残す。技術構成の検討をPDR後まで先送りする指示にはしない。ユースケース・図・モデルの整合だけで、性能や可用性などを含むアーキテクチャの検討・レビューまで完了したと認定しない。

## 指摘と改訂

指摘は「対象箇所／問題と影響／根拠／修正案または決定者への質問」を短く示す。矛盾する数値条件や未合意の業務ルールを、レビュー担当だけで一方に決めない。書籍の例やAIの試案だけを根拠に、概念・関係をプロジェクトで承認された仕様として扱わない。

業務と技術の両方の人が読める具体度にし、合意したこと、残る判断、対応を記録する。非同期なら確認相手を示し、関係者と合意したと推測しない。結果にはレビューの種類、対象範囲、参照した成果物、未検証の範囲を明記する。資料不足の項目を通過扱いにせず、部分レビューの結果をPDR全体の完了へ広げない。

修正を行う場合は、概念・関係・業務ルールの変更をドメインモデルへ戻し、影響するシナリオ・図・要求を読み直す。問題や目的が変わる論点だけ `problem-framing` へ返す。

プロジェクトの運用で必要な場合に限り、重要な分岐と観測できる結果を受け入れ条件へ対応付ける。固定の件数で完成扱いしない。この対応付けは[プロジェクトへの接続](<../../references/books/読書ノート/ユースケース駆動開発実践ガイド/プロジェクトへの接続.md>)に記したローカル運用として扱う。
